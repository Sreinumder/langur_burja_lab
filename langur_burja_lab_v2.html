Payout assumption

For each selected shape: 0 or 1 match returns Rs. 0; 2 or more matches return stake × number of matching dice (gross return, including the original stake). Change this rule in the code if your table uses a different payout.

Research note: Log every roll, including those without bets. Apparent patterns in small samples can happen by chance. Check any potential signal against new rolls before trusting it.
